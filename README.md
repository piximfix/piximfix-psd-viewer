## Key Features

1. **Native Windows Explorer .PSD Thumbnails (Zero Reboot Needed):**
   - Automatically renders .PSD and .PSB files as real image thumbnails inside Windows 10 and Windows 11 File Explorer with a crisp **PSD** corner badge.
   - Activates **instantly** the moment you click **Continue** in the installer—no PC restart required.
2. **Right-Click "Convert PSD to PNG / JPG (Instant)" in File Explorer:**
   - Right-click any .PSD file directly in Windows File Explorer and select **Convert PSD to PNG (Instant)** or **Convert PSD to JPG (Instant)**.
   - Converts full-resolution .PSD files in under 0.3 seconds without launching any window or opening Photoshop.
3. **Ultra-Fast Standalone PSD Image Viewer:**
   - Double-click any .PSD file to open it in under 0.1 seconds.
   - Includes smooth mouse-wheel zoom, click-and-drag pan, ◀ / ▶ folder navigation across all .PSD files in a folder, and 1-click **Save PNG** / **Save JPG** toolbar buttons.
4. **1-Click Complete Uninstall & Instant Cleanup:**
   - Click **Uninstall** inside the Viewer or Setup Manager to immediately remove all files, shortcuts, and Registry entries and restore standard Windows file icons in real time.
